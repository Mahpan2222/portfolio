Posture Estimation for Motorcycle Riders Using Multi-IMU Systems

Mahdi Panahi · Halmstad University / Autoliv

Developing a real-time posture estimation pipeline using multiple IMU sensors mounted on a motorcycle rider. The system combines ESP32 microcontrollers running microROS, MediaPipe for ground-truth pose validation, and sensor fusion via Extended Kalman Filter, Madgwick, and Mahony algorithms.

Smart Greenhouse — Embedded Control System

Designed and implemented a microcontroller-based greenhouse automation system on a SAM3X8E (ARM Cortex-M3) board. The system reads environmental sensors via ADC, controls a servo motor for ventilation via PWM, uses SysTick for precise timing, and manages a dynamically allocated linked list for sensor history. Included an MD5 hashing module for lightweight data integrity verification.

C ARM Cortex-M3 SAM3X8E ADC / PWM SysTick MD5 Linked List

RTMK — Real-Time Micro Kernel

Implemented a real-time operating system kernel from scratch in C as part of the Computer System Engineering II course (DT4013). The kernel includes task administration (INIT/Running state machine, ReadyList/WaitingList/TimerList), inter-process communication via a mailbox FIFO queue (send-wait, receive-wait, send-no-wait, receive-no-wait), and precise timing functions — verified against both static and dynamic scheduling scenarios.

C ARM RTOS Task Scheduling IPC / Mailbox Timer Interrupts

The Decision Tree model achieved R² = 0.9985, demonstrating strong predictive accuracy. Full data cleaning, feature selection, and cross-validation pipeline built in Python.
